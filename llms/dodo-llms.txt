# DODO

> DODO is an on-chain liquidity provider and decentralized exchange (DEX) built on a Proactive Market Maker (PMM) algorithm. Its Trade / Route API aggregates prices across many liquidity sources (DODO v1/v2, 1inch, 0x, ParaSwap, professional market makers) and returns executable ABI calldata for swaps across major EVM chains. Generated by the API Evangelist enrichment pipeline from apis.yml and repo artifacts; DODO does not publish an llms.txt.

## APIs
- [DODO Trade / Route API](https://docs.dodoex.io/en/developer): Real-time swap quotes + ABI calldata across supported EVM chains. Base: https://route-api.dodoex.io
